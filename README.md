# 坦克大战 · Tank Battle

一个纯 HTML / Canvas 的单文件坦克大战小游戏，无需任何依赖，双击 `index.html` 即可在浏览器中运行。

## 玩法

- 控制我方坦克，**保卫基地**（屏幕下方中央的老鹰标志），并**消灭所有敌方坦克**。
- 基地被摧毁，或生命耗尽，则游戏结束。
- 每消灭一波敌人即可进入下一关，关卡会循环并逐步增加敌人数量。

## 操作

| 按键 | 功能 |
| --- | --- |
| `W A S D` / 方向键 | 移动 |
| `空格` / `J` | 射击 |
| `P` | 暂停 / 继续 |
| `R` | 重新开始 |

## 特性

- 三种敌方坦克：普通、快速、装甲（3 点生命）。
- 可破坏的砖块、不可破坏的钢铁、需要守卫的基地。
- 道具掉落：❤️ 加命、🛡 护盾、★ 强化射击。
- 粒子爆炸特效、计分、关卡循环。
- 纯前端，零依赖，移动端与桌面浏览器均可打开。

## 运行

直接用浏览器打开 `index.html`，或在本目录启动一个静态服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```
